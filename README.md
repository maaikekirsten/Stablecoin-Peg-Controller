# Stablecoin-Peg-Controller

> Algorithmic monetary policy controller for maintaining fiat-pegged stablecoins.

## Overview
Core implementation lives under `jobs-ruby/message_broker.rb` alongside modular configuration and telemetry utilities.

## Quick Start
1. Review defaults inside `config/defaults.json`.
2. Run the unit suite under `tests/` before deploying.
